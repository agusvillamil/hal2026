# Ejercicio 1.17

## IDENTIFICAR

## PLANTEAMIENTO
Utilizar los valores extremos de los datos de entrada nos da los valores más grandes y más pequeños de las variables objetivo y a partir de estos obtenemos la incertidumbre.

## EJECUCIÓN
(a) El volumen de un disco de diámetro $d$ y grosor $t$ es $V = \pi ( d / 2 ) ^ { 2 } t$.

El volumen promedio es $V = \pi ( 8 . 5 0 ~ \mathrm { c m } / 2 ) ^ { 2 } ( 0 . 5 0 ~ \mathrm { c m } ) = 2 . 8 3 7 ~ \mathrm { c m } ^ { 3 }$. Pero $t$ se da solo con dos cifras significativas, por lo que la respuesta debe expresarse con dos cifras significativas: $V = 2 . 8 ~ \mathrm { c m } ^ { 3 }$.

Podemos encontrar la incertidumbre en el volumen de la siguiente manera. El volumen podría ser tan grande como $V = \pi ( 8 . 5 2 ~ \mathrm { c m } / 2 ) ^ { 2 } ( 0 . 0 5 5 ~ \mathrm { c m } ) = 3 . 1 ~ \mathrm { c m } ^ { 3 }$, que es $0 . 3 \mathrm { \ c m } ^ { 3 }$ mayor que el valor promedio. La incertidumbre es $\pm 0 . 3 ~ \mathrm { c m } ^ { 3 }$, y expresamos el volumen como $V = 2 . 8 \pm 0 . 3 \mathrm { c m } ^ { 3 }$.

(b) La relación entre el diámetro promedio y el grosor promedio es $8 . 5 0 \ \mathrm { c m } / 0 . 0 5 0 \ \mathrm { c m } = 1 7 0$. Al tomar el valor más grande posible del diámetro y el valor más pequeño posible del grosor, obtenemos el valor más grande posible para esta relación: $8 . 5 2 ~ \mathrm { c m } / 0 . 0 4 5 ~ \mathrm { c m } = 1 9 0$. El valor más pequeño posible de la relación es $8 . 4 8 / 0 . 0 5 5 = 1 5 0$. Por lo tanto, la incertidumbre es $\pm 2 0$ y escribimos la relación como $1 7 0 \pm 2 0$.

## EVALUACIÓN
El grosor es incierto por $10 \%$ y el porcentaje de incertidumbre en el diámetro es mucho menor, por lo que el porcentaje de incertidumbre en el volumen y en la relación debería ser de aproximadamente $10 \%$.
