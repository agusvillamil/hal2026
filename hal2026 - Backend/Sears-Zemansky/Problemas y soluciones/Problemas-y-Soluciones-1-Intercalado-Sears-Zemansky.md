# Ejercicio 1.102
El vector $\vec { r } = x \hat { \imath } + y \hat { \jmath } + z \hat { k }$ llamado vector de posición,, apunta desde el origen $( 0 , 0 , 0 )$ hasta un punto arbitrario en el espacio, cuyas coordenadas son $( x , y , z )$ . Use sus conocimientos de vectores para demostrar que todos los puntos $( x , y , z )$ que satisfacen la ecuación $A x + B y + C z = 0$ , donde $A$ , $B \mathrm { ~ y ~ } C$ son constantes, están en un plano que pasa por el origen y es perpendicular al vector $A { \hat { \imath } } + B { \hat { \jmath } } + C { \hat { k } }$ . Dibuje este vector y el plano.

## IDENTIFICAR
Define $\scriptstyle { \vec { S } } = A { \hat { i } } + B { \hat { j } } + C { \hat { k } }$ . Muestra que $\vec { r } \cdot \vec { S } = 0$ si $A x + B y + C z = 0$

## PLANTEAMIENTO
Utiliza la Ecuación (1.21) para calcular el producto escalar.

## EJECUCIÓN
$$
\quad \vec {\boldsymbol {r}} \cdot \vec {\boldsymbol {S}} = (x \hat {\boldsymbol {i}} + y \hat {\boldsymbol {j}} + z \hat {\boldsymbol {k}}) \cdot (A \hat {\boldsymbol {i}} + B \hat {\boldsymbol {j}} + C \hat {\boldsymbol {k}}) = A x + B y + C z
$$

Si los puntos satisfacen $A x + B y + C z = 0$ , entonces $\vec { r } \cdot \vec { S } { = } 0$ y todos los puntos $\vec { r }$ son perpendiculares a $\vec { s }$ . El vector y el plano se esbozan en la Figura 1.102.

## EVALUACIÓN
Si dos vectores son perpendiculares, su producto escalar es cero.
