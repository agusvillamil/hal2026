Utilice la información sobre el movimiento para encontrar la aceleración y luego utilice $\sum F _ { x } = m a _ { x }$ para calcular $m$.

Sea $+ x$ la dirección de la fuerza. $\sum F _ { x } = 8 0 . 0 \ : \mathrm { N }$.

## EJECUCIÓN

$$

$$

## EVALUACIÓN

# Ejercicio 4.11
Un disco de hockey con masa de $0 . 1 6 0 ~ \mathrm { k g }$ está en reposo en el origen $( x = 0$ ) sobre la pista, que es y sin fricción. En el tiempo $t = 0$ , un jugador aplica una fuerza de $0 . 2 5 0 ~ \mathrm { N }$ al disco, paralela al eje $x$ , y deja de aplicarla en $t = 2 . 0 0 ~ \mathrm { s }$ s. a) $\mathrm { \it ~ \Omega ~ } _ { i } \mathrm { Q u e }$ posición y rapidez tiene el disco en $t = 2 . 0 0 \mathrm { s } ? b$ ) Si se aplica otra vez esa fuerza en $t = 5 . 0 0 ~ \mathrm { s }$ , ¿qué posición y rapidez tiene el disco en $t = 7 . 0 0 \mathrm { s } ^ { \cdot }$ ?

## IDENTIFICAR
Utilice la segunda ley de Newton en forma de componente (Ec. 4.8) para calcular la aceleración producida por la fuerza. Utilice ecuaciones de aceleración constante para calcular el efecto de la aceleración en el movimiento.

## PLANTEAMIENTO

## EJECUCIÓN
(a) Durante este intervalo de tiempo, la aceleración es constante y igual a

$$
a _ {x} = \frac {F _ {x}}{m} = \frac {0 . 2 5 0 \mathrm {N}}{0 . 1 6 0 \mathrm {k g}} = 1. 5 6 2 \mathrm {m} / \mathrm {s} ^ {2}
$$

Podemos utilizar las ecuaciones cinemáticas de aceleración constante del Capítulo 2.

$$
x - x _ {0} = v _ {0 x} t + \frac {1}{2} a _ {x} t ^ {2} = 0 + \frac {1}{2} (1. 5 6 2 \mathrm {m} / \mathrm {s} ^ {2}) (2. 0 0 \mathrm {s}) ^ {2},
$$

por lo que el disco está en $x = 3 . 1 2 \mathrm { m }$

$$
v _ {x} = v _ {0 x} + a _ {x} t = 0 + (1. 5 6 2 \mathrm {m} / \mathrm {s} ^ {2}) (2. 0 0 \mathrm {s}) = 3. 1 3 \mathrm {m} / \mathrm {s}.
$$

(b) En el intervalo de tiempo desde $t = 2 . 0 0 ~ \mathrm { s }$ hasta 5,00 s, la fuerza ha sido eliminada, por lo que la aceleración es cero. La velocidad permanece constante en $\nu _ { _ { x } } = 3 . 1 2 ~ \mathrm { m / s }$ La distancia que recorre el disco es $x - x _ { 0 } = \nu _ { 0 x } t = ( 3 . 1 2 \mathrm { m / s } ) ( 5 . 0 0 \mathrm { s } - 2 . 0 0 \mathrm { s } ) = 9 . 3 6 \mathrm { m / s }$ Al final del intervalo, está en $x = x _ { 0 } + 9 . 3 6 ~ \mathrm { m } = 1 2 . 5 ~ \mathrm { m }$ .

En el intervalo de tiempo desde $t = 5 . 0 0 ~ \mathrm { s }$ hasta 7,00 s, la aceleración es nuevamente $a _ { x } = 1 . 5 6 2 ~ \mathrm { m / s } ^ { 2 }$ Al comienzo de este intervalo, $\nu _ { 0 x } = 3 . 1 2 ~ \mathrm { m / s }$ y $x _ { 0 } = 1 2 . 5 ~ \mathrm { m }$ .

$$
x - x _ {0} = v _ {0 x} t + \frac {1}{2} a _ {x} t ^ {2} = (3. 1 2 \mathrm {m} / \mathrm {s}) (2. 0 0 \mathrm {s}) + \frac {1}{2} (1. 5 6 2 \mathrm {m} / \mathrm {s} ^ {2}) (2. 0 0 \mathrm {s}) ^ {2}.
$$

$$
x - x _ {0} = 6. 2 4 \mathrm {m} + 3. 1 2 \mathrm {m} = 9. 3 6 \mathrm {m}.
$$

Por lo tanto, en $t = 7 . 0 0 ~ \mathrm { s }$, el disco está en $x = x _ { \scriptscriptstyle 0 } + 9 . 3 6 ~ \mathrm { m } = 1 2 . 5 ~ \mathrm { m } + 9 . 3 6 ~ \mathrm { m } = 2 1 . 9 ~ \mathrm { m } .$

$$
v _ {x} = v _ {0 x} + a _ {x} t = 3. 1 2 \mathrm {m} / \mathrm {s} + (1. 5 6 2 \mathrm {m} / \mathrm {s} ^ {2}) (2. 0 0 \mathrm {s}) = 6. 2 4 \mathrm {m} / \mathrm {s}
$$

## EVALUACIÓN
La aceleración indica que el disco gana $1 . 5 6 \mathrm { m / s }$ de velocidad por cada segundo que actúa la fuerza. La fuerza actúa un total de 4,00 s, por lo que la velocidad final es $( 1 . 5 6 ~ \mathrm { m / s } ) ( 4 . 0 ~ \mathrm { s } ) = 6 . 2 4 ~ \mathrm { m / s }$ .
