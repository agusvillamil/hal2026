# Ejercicio 12.88
Fuerzas de marea cerca de un agujero negro. Una astronauta, dentro de una nave que la protege de las radiaciones dañinas, está en órbita alrededor de un agujero negro a una distancia de 120 km de su centro. El agujero tiene 5.00 veces la masa del Sol y un radio de Schwarzschild de 15.0 km. La astronauta está situada dentro de la nave, de modo tal que una de sus orejas de 0.030 kg está 6.0 cm más lejos del agujero negro que el centro de masa de la nave, y la otra oreja está 6.0 cm más cerca. a) $\mathrm { \it ~ \Omega ~ } _ { i } \mathrm { Q u e }$ tensión hay entre las orejas? ¿Sería difícil para la astronauta evitar ser desgarrada por las fuerzas gravitacionales? (Puesto que todo su cuerpo está en órbita con la misma velocidad angular, una oreja se mueve con demasiada lentitud para el radio de su órbita y la otra lo hace con demasiada rapidez. Por ello, la cabeza debe ejercer fuerzas sobre las orejas para mantenerlas en sus órbitas.) b) $\mathrm { _ { i } f }$ l centro de gravedad de la cabeza está en el mismo punto que su centro de masa? Explique.

## IDENTIFICAR
Aplicar $\sum { \vec { F } } = m { \vec { \pmb { a } } }$ a cada oreja.

## PLANTEAMIENTO
Denotar el radio de la órbita como $r$ y la distancia desde este radio a cualquiera de las orejas como δ. Cada oreja, de masa $m$, puede ser modelada como sujeta a dos fuerzas, la fuerza gravitatoria del agujero negro y la fuerza de tensión (en realidad la fuerza de los tejidos del cuerpo), denotada por $F$.

## EJECUCIÓN
La ecuación de fuerza para cualquiera de las orejas es ${ \frac { G M m } { \left( r + \delta \right) ^ { 2 } } } - F = m \omega ^ { 2 } ( r + \delta )$ GMm, donde $\delta$ puede ser de cualquier signo.

Reemplazar el producto $m \omega ^ { 2 }$ con el valor para $\delta = 0$, $m \omega ^ { 2 } = G M m / r ^ { 3 }$, y resolver para $F$:

$$
F = (G M m) \left[ \frac {r + \delta}{r ^ {3}} - \frac {1}{(r + \delta) ^ {2}} \right] = \frac {G M m}{r ^ {3}} \left[ r + \delta - r (1 + (\delta / r)) ^ {- 2} \right].
$$

Usando el teorema binomial para expandir el término entre corchetes en potencias de $\delta / r$,

$$
F \approx \frac {G M m}{r ^ {3}} \left[ r + \delta - r (1 - 2 (\delta / r)) \right] = \frac {G M m}{r ^ {3}} (3 \delta) = 2. 1 \mathrm {k N}.
$$

Esta tensión es mucho mayor que la que podría ser sostenida por el tejido humano, y el astronauta está en problemas.

(b) El centro de gravedad no es el centro de masa. La fuerza gravitatoria en las dos orejas no es la misma.

## EVALUACIÓN
La tensión entre sus orejas es proporcional a su separación.
